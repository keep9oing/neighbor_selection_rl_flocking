## 1. 요약 (숫자 먼저)

**사전 등록 3가설 중 H-A(보험 유일성)·H-B(비율 규칙 N-전이 실패) 생존,
H-C(C1 풀-내 보험)는 미충족 — C1의 L125 구멍(4.0%)이 드러났다.**
위협 가설("더 큰 고정 k가 싼 신뢰성을 산다")은 측정으로 반증됐다.

프런티어 표 (n=500/조건, 시드 1000-1499; 셀 = 실패% / 성공-J중앙값 / CVaR10):

| 암 | L125 | L250 | L500 |
|---|---|---|---|
| k12 | 4.0 / 147.7 / 377 | 8.0 / 160.3 / 316 | 9.0 / 166.3 / 349 |
| k13 (=규칙 0.65N) | 4.2 / 144.9 / 341 | 5.0 / 161.6 / 353 | 7.2 / 167.3 / 365 |
| k14 (=규칙 0.7N) | 3.4 / 147.3 / 333 | 7.8 / 161.0 / 391 | 10.2 / 161.3 / 375 |
| k16 | 4.8 / 166.0 / 319 | 10.2 / 162.7 / 361 | 15.0 / 169.8 / 329 |
| k18 | 9.8 / 206.2 / 420 | 13.8 / 183.3 / 412 | 9.2 / 194.8 / 441 |
| FC(k19) | **0.0** / 236.7 / 560 | **0.0** / 199.9 / 520 | **0.0** / 226.4 / 534 |
| **C1 it80** | 4.0 / **139.3** / **273** | **0.2** / **158.6** / **303** | 0.4 / 205.5 / 468 |
| **R1 it110** | **0.0** / 185.5 / 358 | **0.0** / 192.9 / 308 | **0.2** / 236.4 / 490 |
| A60 (전문가) | — | 2.2 / 155.7 / 320 | — |

- **H-A 생존 (4/4 셀)**: 기준 (i) 실패≤1%(양 L)를 충족한 고정-k 암이
  전무 — 최소가 k13@L250의 5.0%. 신뢰성은 k에 평탄~악화(비단조)라
  "k를 키우면 싸게 산다"는 경로 자체가 없다. 사후 확장(A3)으로
  **N=20 k=8~18 연속 전 구간 + N=10/N=40까지 n=500으로 확인** — 측정된
  모든 고정 k(총 17조건)가 2.8~15.0% 실패로, 반증 기회를 넓힐수록
  주장이 강화됐다(§4.1).
- **FC 절벽**: k18(전 L 9~14% 실패) → k19=FC(0/1500) 한-엣지 절벽.
  유일하게 신뢰 가능한 고정 위상 FC의 전형-J 프리미엄(k12 대비
  +40~+89)은 정책들 프리미엄보다 크고, **C1은 전 L에서 FC보다 전형-J
  우세**(139/159/206 vs 237/200/226), CVaR10도 전 L 우세.
- **H-C 미충족**: C1@L125 20/500(4.0%) — k12와 동률(McNemar b=18 cc=18
  p=1). 풀링 23/1500=1.53%>1%. L250/L500은 1·2건으로 보험급(각 McNemar
  p≤4e-11). **풀 전체 보험은 R1만** (0+0+1=1/1500=0.07%).
- **H-B 생존**: 규칙 k7@N10에 C1 압승(페어드 중앙값 −48.4, w_p 8.7e-4;
  성공 32/32 vs 30/32) + 규칙 자기-k(13/14)가 전 L에서 3.4~10.2% 실패.
  k26@N40은 규칙 우세(C1 +22.6, p=0.0076) — r2 철회와 정합.
- **실패 기전 확정(census, 전 실패 에피소드)**: 실패의 ~80-100%가
  [19+1] 분리 — 무리가 낙오자 1기를 farthest로 버리고 낙오자만 추격하는
  **비대칭 버림(straggler abandonment)**. k18 실패는 전 L에서 100%
  [19+1](164/164) — 기전 예측 그대로. FC(전원 연결)에서만 소멸.

## 4. 핵심 발견

### 4.1 고정-k의 실패 꼬리는 k-보편·N-보편 결함이다 (희소성 문제가 아님)
k12의 8~9%(S1)는 "k가 작아서"가 아니었다. 사용자 질문(§A3)에 따라
N=20에서 **k=8~19 연속 스윕을 n=500으로 완성**한 결과 (실패% / 성공-J중앙값):

| k | L125 | L250 | L500 |
|---|---|---|---|
| 8 | 14.0 / 150.7 | 8.4 / 164.2 | 15.0 / 193.0 |
| 9 | 4.6 / 145.8 | 5.8 / 167.0 | 8.4 / 183.9 |
| 10 | 4.0 / **142.2** | 5.2 / 164.9 | 7.2 / 176.5 |
| 11 | **2.8** / 143.4 | 6.2 / 162.5 | 8.2 / 172.4 |
| 12 | 4.0 / 147.7 | 8.0 / **160.3** | 9.0 / 166.3 |
| 13 | 4.2 / 144.9 | **5.0** / 161.6 | **7.2** / 167.3 |
| 14 | 3.4 / 147.3 | 7.8 / 161.0 | 10.2 / 161.3 |
| 15 | 7.2 / 154.8 | 6.2 / 161.9 | 12.8 / **161.2** |
| 16 | 4.8 / 166.0 | 10.2 / 162.7 | 15.0 / 169.8 |
| 17 | 8.6 / 180.8 | 10.4 / 173.6 | 11.6 / 179.2 |
| 18 | 9.8 / 206.2 | 13.8 / 183.3 | 9.2 / 194.8 |
| **19=FC** | **0.0** / 236.7 | **0.0** / 199.9 | **0.0** / 226.4 |

**k=8~18의 11개 값 전부가 2.8~15.0% 실패한다.** 실패율은 k에 비단조이고
(L500 최악은 k16의 15.0%), 어떤 k도 1% 근처에 없다 — 조건별 최소가
2.8%(k11@L125) / 5.0%(k13@L250) / 7.2%(k10·k13@L500)다. 반면 정책은
같은 조건에서 R1 0.0~0.2% / C1 0.2~0.4%(L≥250; L125는 4.0%, §4.4).
성공-J 최저는 L마다 다른 k에 있고(L125 k10 142.2, L250 k12 160.3,
L500 k15 161.2 — k14의 161.3과 사실상 동률), k16부터는 전 L에서 상승 —
**효율 프런티어와 신뢰성은 k축에서 독립적으로 나쁘다**. N축(n=500)도 같다: N=10 k6/k7/k8 =
4.2/6.8/8.2%, N=40 k24/k26/k28 = 3.6/5.6/3.6%. **꼬리는 k-보편이자
N-보편이며, k=N−1(FC)에서만 소멸한다.**

### 4.2 병합 실패의 기전: 비대칭 낙오자-버림, 그리고 FC 절벽
전 실패 에피소드 census: 최종 상태는 정렬 완벽(phi≈1.0)·공간 안정인
채 성분 2개 — 압도적 다수가 [19+1](낙오자 1기). 기전: k-NN에서 무리
19기는 낙오자를 farthest로 제외(당김 없음), 낙오자만 무리를 향해
추격 — 등속이라 영원히 미병합. k18은 정확히 "자기 farthest 1기만
제외"이므로 실패가 100% [19+1]이고, k19=FC(전원 연결)에서 무리도
낙오자를 당기므로 소멸(0/1500). 소수 모드: [18+2]·[17+3](작은 k),
[20] 4건(단일 성분인데 판정 실패 — 경계/지연 수렴; R1의 유일 실패
시드 1127도 [20], r2의 phi 0.9804 경계 사례와 동일 건).

### 4.3 H-A 상세: 정책의 위치는 프런티어 그 자체
- **L250에서 C1은 측정된 모든 고정-k를 파레토-지배**: 전형-J 동급~우세
  (vs k13 −1.7 n.s., k14 −3.5 p=.011, k16 −4.8 p=.0023, k18 −17.7
  p=2.8e-9) + 실패 1 vs 25~69 (McNemar 전부 p≤8e-7).
- L500에서 C1은 규칙-k 대비 전형 +39~+42를 내지만(각 p<1e-28) 그
  암들은 7~10% 실패; 신뢰 대안 FC 대비로는 C1이 −21 우세.
- R1은 전 조건 +26~+68 프리미엄에 실패 0~1 — 순수 보험 정책. 단
  L500에선 FC(226.4)가 R1(236.4)보다 전형-J도 싸다: **L500 한정,
  R1의 보험료는 FC 프리미엄을 초과**(C1은 아님).

### 4.4 H-C: C1의 저-L 구멍 — 풀-내 보험은 R1만
C1@L125: 실패 20/500(4.0%), k12와 동률(불일치 시드 18:18, p=1;
겹침 실패 2건뿐 — 같은 기전, 다른 시드). 전형-J는 k12보다 우세
(−7.7, p=1.6e-4)라 C1@L125는 "프런티어보다 싸지만 고정-k급 위험".
반면 R1은 0/500 (+38.0 프리미엄, p=1.5e-24). r2의 32-시드 그리드
(31/32)는 이 구멍을 해상도 부족으로 못 봤다 — C1의 L75 취약(J 315)과
연속된 저-L 결함으로 읽힌다. 실패 kNN-대비 순증가는 아님(동률)이나
"보험" 명칭은 L≥250에서만 정당.

### 4.5 H-B: 비율 규칙의 실측 — 저-N 실패 확정, N40 우세 재확인
- k7@N10(=0.65·10): 30/32, J 186.3 — C1(32/32, 145.0)에 페어드 중앙값
  −48.4(w_p 8.7e-4, 열세 7/30)로 완패. 기존 k6/k8/FC 결과와 합쳐
  **저-N에서 어떤 고정 k도(6/7/8/9) C1을 못 따른다**가 완결됨.
- k26@N40(=0.65·40): 30/32, J 147.9 — C1이 +22.6 열세(p=.0076), R1은
  +47.1(p=2e-4). r2의 N=40 철회 유지: 규칙은 N=40 전형-J에서 우세.
- 규칙 자기-k(13/14)의 신뢰성: §4.1 — 규칙은 N=20에서 J만 맞고 위험은
  그대로. **"k∝0.65N 규칙"은 (전형-J, N≥40)에서만 이기고, 저-N에서
  지며, 자기 스케일 신뢰성 결함을 계승한다.**

### 4.6 보간·외삽 참조 신설: 고정-k는 보간에서도 샌다
L375/L750에 k-NN 참조가 이번에 처음 생겼다(32-시드):
- **L375(보간)**: k12 26/32(J 179.1), k16 25/32 — 풀 중간에서 프런티어
  자체가 6~7건 실패. C1 32/32·178.3(J 동급 +3.4 n.s., 성공 McNemar
  p=.031) — **r2가 "전문가급"이라 부른 C1의 L375는 실은 고정-k 양축
  지배 지점**. R1 32/32(+55.0 J 열세).
- **L750(외삽)**: k12 26/32(200.1), k16 28/32, FC 32/32(304.0). C1
  29/32(282.3, J +77 열세·성공차 n.s.) — **C1의 "외삽 취약"조차 고정-k
  프런티어보다 성공률이 높다**. R1 32/32(유일 무결점, J +133).
- A60 외삽 참고: L750 +194 열세(p=5e-6) — 전문가의 스케일 밖 붕괴 재확인.

### 4.7 정밀화된 2-정책 파레토와 정책의 실체
- **R1 it110**: 전 측정 조건 무실패에 가장 근접(풀-내 1500 중 1, 그마저
  정렬-문턱 경계). L 75~750·N 10~40 통산 성공 손실 0. 비용: 전형-J
  +27~+133. **"보험 정책"의 자격이 이번 라운드로 완성**.
- **C1 it80**: L≥250 풀-내에서 실패율·CVaR·전형-J 모두 프런티어
  이상(파레토-지배 다수), L375 보간 지배, L750도 고정-k 우위. 결함:
  L125 4.0%(±L75 J 폭증) — **저-L 병합만이 남은 구멍**.
- 관찰: C1의 정상 상태 차수는 준-FC(deg_ss 중앙값 ~18.1)인데 J는
  FC보다 40~80 낮다 — 승리는 희소성이 아니라 **시점-선택적 위상**
  (초기 rank_dev 0.19 → 정상 0.06)에서 온다. 낙오자-버림을 학습
  정책이 회피하는 기전 서술의 출발점.

## 5. 정직한 판정 (사전 등록 대비)

- H-A: **생존** — 4/4 셀에서 기준 (i)+(ii) 동시 충족 암 없음 (최소
  실패율 5.0% ≫ 1%). 판정 규칙 원문·정정 이력 PROBLEM.md.
- H-B: **생존** — b1 충족(두 경로 중 Wilcoxon 경로; McNemar는 0:2로
  방향 일치·비유의) AND 규칙-k 신뢰성 결함(전 L 3.4~10.2%).
- H-C: **미충족** — 풀링 1.53%>1%, L125 McNemar 비유의. L250/500 다리는
  충족. 판정은 등록 문구 그대로; "부분 보험(L≥250)"이 정직한 서술.
- 정정 A1(사전)·A2(사후-관찰, 사전-데이터) 2건 — 본문·RUNLOG에 기록.
- 재현성 앵커: 분석 §0이 r2 공표치(460/455) 재현 후에만 진행.

  성능 미화뿐.
2. **풀 확장 {75..750}**: 동기 약화 — C1의 실제 구멍은 풀-**내**
  L125(4.0%)이고, L750 외삽은 이미 고정-k보다 낫다. 확장보다 **저-L
  병합 신뢰성**(예: L125-가중 혼합 재학습, R1-C1 스위치/앙상블)이
  다음 학습 후보로 더 정확한 표적.
3. **기준 재설계(실패율+CVaR 1차)**: 이번 데이터로 강하게 동기화 —
  그 축에서 C1(L≥250)·R1이 FC 포함 전 측정 대안을 지배/동급-우세.
  단 원칙 유지: 새 기준은 사전 등록 + 새 시드 재검증 전제(온전히
  사용자 결정).
4. **논문 재료(신규)**: (a) 낙오자-버림 기전 — census·k18 100%·FC
  절벽의 3중 증거로 "고정-k의 구조적 신뢰성 결함" 서술 가능; (b)
  보간 구멍(L375 26/32) — "고정-k는 스케일 그리드 사이에서도 샌다";
  (c) distillation 기준선의 정확한 상한: 전형-J N≥40에서만 학습 정책
  우세, 신뢰성·저-N·보간에서 열세.

### 4.8 조건별 최적 k는 존재하지만(효율만) 신뢰성은 못 산다 (사용자 질문 A3)
"N·L마다 적절한 k가 따로 있지 않나"에 대한 실측 답. **효율 축에서는
사용자 직관이 맞다**: J-최적 k가 L에 따라 완만히 상승한다 (L125 k10
142.2 → L250 k12 160.3 → L500 k14/k15 161.3/161.2 동률). 그러나 (a)
튜닝 이득이 작고(k12 고정 대비 J −5.5/0/−5.1, 3% 남짓), (b) **신뢰성은
오라클로도 못 산다** — 조건별 오라클(사후에 조건을 알고 고르는 반칙)로
최소 실패율을 골라도 2.8/5.0/7.2%인데, R1은 0.0/0.0/0.2%로 전 조건에서
차원이 다르고, C1도 L250 0.2%·L500 0.4%로 오라클보다 한 자릿수 이상
낮다. 유일한 예외가 L125: 오라클 k11(실패 14/500)이 C1(20/500)보다
적으나 페어드 McNemar p=0.39로 통계적 동률이고, J는 C1이 −6.2 우세
(w_p=1.8e-4); R1(0/500) 상대로는 k11도 완패(McNemar p=1.2e-4). 게다가
J-최적 k와 실패-최소 k가 같은 L에서 서로 다르다(L500: J는 k14/k15,
실패는 k10·k13) — 단일 k로 두 축을 동시에 최적화하는 지점 자체가 없다. 기전(§4.2)이 k 값이
아니라 **비대칭 절단이라는 구조**에서 오기 때문이다. 덧붙여 조건별
오라클 k는 N·L을 미리 알아야 하는 방법이라, 조건을 모른 채 단일
체크포인트로 동작하는 학습 정책과는 주장의 급이 다르다.
